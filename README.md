# 🐨 코알라 다마고치

픽셀 아트 코알라를 키우는 브라우저 다마고치 게임입니다.
[링크] (https://lanymo.github.io/koala-tamagotchi)
---

## 게임 방법

화면 하단의 버튼 세 개로 코알라를 돌봐주세요.

| 버튼 | 효과 |
|------|------|
| 🍃 밥주기 | 배고픔 회복, 경험치 획득 |
| 🎮 놀기 | 행복도 회복, 경험치 획득 |
| 😴 재우기 | 피로도 회복, 경험치 획득 |

---

## 스탯

- **배고픔**: 시간이 지날수록 감소합니다.
- **행복도**: 시간이 지날수록 감소합니다.
- **피로도**: 활동할수록 증가합니다.
- **경험치**: 행동할 때마다 쌓입니다.

배고픔과 행복도가 **동시에 0**이 되면 코알라가 쓰러집니다.

---

## 표정

| 표정 | 조건 |
|------|------|
| 신남 😄 | 최근에 밥을 먹거나 놀았을 때 |
| 보통 🙂 | 평상시 |
| 슬픔 😢 | 배고픔 또는 행복도가 낮을 때 |
| 화남 😠 | 잠자는 중에 간식을 줬을 때 |
| 수면 😴 | 재우기 중 |
| 사망 💀 | 배고픔 + 행복도 동시에 0 |

---

## 레벨 시스템

경험치를 쌓으면 레벨이 오릅니다.

| 레벨 | 이름 | 필요 경험치 |
|------|------|------------|
| LV 1 | 아기 코알라 | 30 |
| LV 2 | 꼬마 코알라 | 70 |
| LV 3 | 청소년 코알라 | 120 |
| LV 4 | 어른 코알라 | - |

---

## 진화 시스템

LV 4 달성 후 플레이 패턴에 따라 5가지 유형으로 진화합니다.
밥 횟수(feedCount), 놀기 횟수(playCount), 재우기 횟수(sleepCount)의 비율로 결정됩니다.

진화하면 각 챔피언 테마의 픽셀 아트 외형이 추가됩니다.

---

## 저장

게임 상태는 브라우저의 `localStorage`에 자동 저장됩니다.
브라우저를 닫아도 코알라는 그대로 남아있습니다.
